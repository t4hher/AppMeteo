# 🌤️ AppMeteo - Responsive Weather Dashboard

A modern, responsive weather application built with **React** and **Redux Toolkit**. This project features real-time weather tracking, hourly forecasts, and a dynamic theme-switching system (Light/Dark mode) that automatically adapts to the time of day at the searched location.

## ✨ Features
* **Real-time Weather:** Fetches live data including temperature, humidity, and wind speed.
* **Automatic Theme Engine:** Seamlessly switches between Light and Dark modes based on `is_day` data from the API.
* **Hourly & Daily Forecasts:** Interactive horizontal scrolling for hourly data and a clean grid for daily outlooks.
* **Fully Responsive:** Optimized for desktop, tablet, and mobile devices using CSS Grid and Flexbox.
* **Global State Management:** Powered by Redux Toolkit for predictable state transitions.

## 🚀 Tech Stack
* **Frontend:** React (Hooks, Functional Components)
* **State Management:** Redux Toolkit (Slices & Async Thunks)
* **Styling:** Vanilla CSS (Custom Variables/Theming)
* **Deployment:** GitHub Pages
* **API: OpenWeather (via Axios)
